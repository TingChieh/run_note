# 首页全年日历与运动足迹

## 使用

- 首页日历完整显示全年日期，普通年 365 天、闰年 366 天。桌面使用随容器适配的热力图，手机按 12 个月分组，无须横向拖动才能看到年末。仍可切换距离/次数，点击日期展开当天活动，使用方向键及 Home/End 浏览。
- 年份“查看”按钮已移除。输入 1900–2100 范围的四位年份会自动刷新，也可用左右按钮切年。快速切换只接受最后一次请求，保留 URL 参数、日期恢复及失败重试。
- 首页“运动足迹”默认读取最近 20 条记录并选中最新一条，跨月份浏览，保留每条记录日期；上方显示名称、日期、开始时间/时区、地图以及距离、设备用时/经过时间、配速、平均心率、热量、步数。缺失用 —、真实零值保留，设备计时与经过时间分开。七项指标保持固定位置，缺少设备计时也不会减少卡片。
- 年月选择器和追加分页已移除。分类选项来自本人的全部历史记录，另有“全部”和“未分类”。每次切换分类读取该分类最近 20 条，与日历年份独立。下方横向卡片可左右滑动或用键盘选择，左右记录箭头仅在这 20 条内浏览。没有记录的分类显示空状态。这里浏览的是已有运动，不创建未来计划。
- 点击卡片或切换分类时保留原面板、地图和指标，详情与路线读取完毕后一起更新。标题及指标数值柔和淡出/淡入，背景保持稳定；已绘制的嵌入地图不会因换轨迹再次弹出绘制提示。标题预留两行，地图与指标区不因单条切换或缺少路线而折叠；路线读取失败可单独重试，没有路线仍显示指标。可通过“活动详情”进入完整详情。
- 主导航新增独立“足迹墙”，沿用 `/activities/wall`，进入后只高亮足迹墙，不再同时高亮跑步记录。既有足迹墙、跑步记录编辑/删除和个人足迹地图继续保留。

## 接口与隐私

`GET /api/v1/activities/categories` 返回本人所有活动的去重分类字符串数组（可包含空字符串），复用现有身份验证；不暴露其他用户分类。既有活动列表增加可选 `category` 查询参数，最多 30 字符、精确匹配，空字符串代表未分类，省略表示全部。新增可选 `activity_month=YYYY-MM` 按活动本地日期的整月范围筛选（含闰年二月）。与 activity_date、category、limit、offset 共同工作，无数据库变更。

列表、详情、路线和分类分别处理失败；分类及单条切换保留当前展示，新的详情和路线完成后一起更新，序号校验避免晚到响应覆盖当前选择。首页足迹不再发送 activity_month 或 activity_date，接口对月份参数的支持保留。同一地图更新 GeoJSON、起终点及视野，保留底图开关状态，避免反复初始化。任一首页读取（含懒加载小足迹）返回 401，会同步清除私人地图、指标和卡片，失效所有旧请求，再跳转登录。轨迹按原地图逻辑本地绘制，测试拦截外部瓦片请求，不调用真实 AI。
