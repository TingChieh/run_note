04 · 已暂停 / Paused 防误停交互

安全门禁
  • 目的：明确区分「恢复继续」「正式结束」与「危险丢弃」三种意图层级。
  • 主操作与无障碍兜底：主绿按钮「继续跑步」；「结束并保存」采用长按 1.5s 进度条，且单击可弹出原生确认框（满足 WCAG 2.5.1 与开关控制无障碍替代）。
  • 危险隔离：「放弃本次」移至右上角远拇指区，点击必须经原生 <dialog> 二次确认。
  • 口径透明：保留 Phase 3 暂停影响服务端总耗时配速的诚实提示，避免用户对最终配速产生困惑。
