# 首页紧凑布局、累计足迹与明暗切换

用户目标：目标区稍微缩小，运动足迹在多数桌面屏幕完整展示；首页省份反映全部历史；运动日历颜色更明显；新增黑夜模式按钮。

## 设计

- 保留目标区两列结构，减少卡片内边距与省份 SVG 高度，完整保留地图比例和南海附图。
- 运动足迹只调整呈现：标题收紧、指标采用图标与文字并排的小卡片、地图使用局部 CSS 高度变量，桌面按视口高度缩放。1024px 起并列显示路线与指标，小屏纵向排列。路线缺失时保留相同空间，避免切换抖动；不设置整个面板的裁切高度。
- 省份接口 year 可选，不传时在 SQL 中取消日期过滤，返回 year=null。按年调用保持原有结构与规则；首页不再传年份，文案明确为全部时间。鉴权、用户归属、坐标隐私与计算预算沿用现有逻辑。
- 日历使用颜色令牌增强活动强弱差异，并排除覆盖数据颜色的通用玻璃高光/阴影；保留键盘、选中态和移动端日期文字。
- 外观默认系统自动。桌面侧栏、移动端顶栏、公开/登录页提供明暗切换按钮；手动选择后提供“自动”按钮恢复系统同步。仅存本机外观枚举，不经 API。
- 首屏脚本在渲染前应用偏好；根布局统一监听系统和跨页签变化，地图/图表沿用已有订阅更新颜色，不重建实例。存储不可用时仍可切换当前页。

## 验证范围

合成 API 的真实 Chrome 验证桌面 1366×768、1440×900、1920×1080、1024×768 足迹整块高度，以及 320/390px 无横向溢出、目标编辑与记录切换、日历五档文字对比和主题保留草稿/刷新记忆/恢复系统、地图画布复用。真实独立 PostGIS 测试覆盖跨年聚合、按年兼容、他人隔离、匿名拒绝和无坐标响应。
