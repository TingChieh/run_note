# 全站 Liquid Glass 按钮设计

用户要求将首页左右按钮的玻璃效果扩展到所有按钮，并指定 https://liquidglass.dev/docs/ 与 https://github.com/gentpan/liquidglass 作为实现依据。保留按钮布局、形状、语义颜色、原生表单、点击行为与键盘焦点。

## 实现方案

本地保存 MIT 许可的 v1.0.0 核心引擎，固定上游提交 `068ad226f53e1ca62d857f78bdc32f58f3c5fce7`，保留许可证与来源信息。原始 JS 不改写，用独立声明文件约束实际调用的 API。不载入示例图片或自定义元素组件，不在运行时执行 CDN 脚本。

共享 Svelte action 在客户端动态载入引擎，原生按钮和按钮样式链接使用 `createGlass(..., {mode: 'backdrop', fit: true})`。SVG 位移仅折射背景，文字与图标不经内容滤镜。MutationObserver 为新增按钮接入效果，为移除按钮销毁实例；ResizeObserver 跟随响应式尺寸更新圆角。卸载时释放监听、观察器、待执行帧与所有实例。

共享 CSS 提供半透明填色、内高光、柔和阴影与悬停提亮。主要操作保留主色，删除确认保留警示色，侧栏适配绿色底。日历日期保留数据色阶、今天/选中标记；日期格、历史大卡片、文件选择伪元素使用轻量 CSS 材质，避免为数百个日期或复杂卡片创建 SVG 滤镜。地图署名按钮保留原有背景图标。

沿用首页箭头在边框上的定位、SVG 居中和桌面/手机尺寸，移除其重复材质定义。按官方文档不对玻璃按钮施加缩放，使用颜色和阴影过渡。

## 兼容与隐私

Chrome 使用 SVG 背景折射；Safari / Firefox 使用官方磨砂回退，不承诺跨引擎背景折射一致。无 backdrop-filter 时保留原有实色底。减少透明度或强制颜色时销毁引擎实例并使用实色；减少动态效果时关闭 CSS 过渡。

引擎只在本地 canvas 生成位移 PNG 与 SVG 定义，不复制私人 DOM，不发网络请求。认证、接口、数据库、坐标和地图数据行为保持原状。
