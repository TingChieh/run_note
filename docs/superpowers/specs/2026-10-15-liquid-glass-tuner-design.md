# Liquid Glass 通透增强与开发调节面板

用户希望玻璃更明显、更通透，并能在 dev 端调整预览。沿用已接入的官方引擎，不改写上游、不改变活动或表单业务。

## 交互与边界

开发环境右下角提供“玻璃调节”折叠入口。面板提供透明度、折射强度、模糊和边缘高光四项实时滑块、通透/柔和预设和恢复默认。整页按钮同步变化，面板有彩色条纹预览区供观察边缘折射；键盘可操作滑块，Escape 收起面板并将焦点归还入口。窄屏控制宽高并允许面板自身滚动。

参数保存在当前浏览器专用 localStorage 键，限制数值范围、忽略未知字段、处理损坏或不可用存储。参数变化不触发活动请求或保存，不包含用户/轨迹信息。面板及存储读写只在 `import.meta.env.DEV` 下加载；生产构建使用新的统一默认材质，不提供调节入口且不读取开发偏好。

## 实现

共享设置模块定义安全范围、默认值、开发环境偏好读写和变更通知。现有 Svelte action 读取设置、更新根透明度变量并批量调用已有引擎实例 update，避免拖动时销毁重建控件。非 Chrome 按当前模糊值更新官方回退效果。减少透明度/强制颜色优先于开发预览。

默认透明度提高到 78%，折射 18px，模糊 0.6px，高光 0.65。中性按钮与语义填色随透明度变化；主要/危险按钮采用适合浅深色的文字色，深色主题降低语义染色权重保证可读性。透明度范围 45–95%，保留焦点、禁用和选中标记。日历、复杂历史卡和文件伪按钮继续使用轻量 CSS 材质，不增加 SVG 实例。

## 验证

测试数值边界、损坏偏好、实时更新现有/动态按钮、刷新保留、恢复默认、键盘收起、320px 布局与系统偏好优先级。执行类型检查、构建和 Chrome 合成 UI 回归；生产构建中确认无调节模块/文案，并确认生产页面不读取开发偏好。保留无数据库、无真实后端/用户数据的验证边界。
