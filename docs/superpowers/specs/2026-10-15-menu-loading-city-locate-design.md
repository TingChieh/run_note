# 菜单加载与城市定位设计

用户已确认：菜单切换采用骨架屏＋淡入；城市按钮用于定位地图并保留全部足迹。2026-10-16 补充：手机用菜单选择，电脑直接展示所有有记录的城市。

## 菜单加载

侧栏、目标草稿和登录检查机制继续复用。SvelteKit 实际导航时在右侧显示骨架屏，旧页面保持挂载但隐藏且不可交互；导航结束立即移除骨架，无最短展示时长。目标页面挂载时淡入。活动、足迹墙、年度日历、个人足迹和 AI 依据的现有数据加载分支复用同一骨架组件，数据出现时淡入。设置页无额外读取，不制造加载时间。

骨架使用现有主题令牌，提供中文加载状态；系统减少动态效果时禁用骨架动画和淡入。失败沿用原有错误与重试，不让骨架持续遮挡内容。

## 城市定位

足迹接口没有城市字段，使用与项目省份地图同源的 DataV 城市可视化边界，随前端本地打包，在 Worker 内对当前轨迹或热区做空间相交估算。只显示有几何记录相交的城市/地区；直辖市按整市合并，不展示区级按钮。城市读取不改变服务端权威统计。

1024px 及以上直接平铺全部匹配城市按钮，自动换行；1024px 以下（与应用导航断点一致）使用“城市”菜单和选择框。选中城市后定位该城市范围内已有几何的包围范围，保留所有数据源、路线、记录和热区；回到全部足迹恢复概览。两种地图模式共用，初始化失败时禁用定位。

识别不发送坐标到任何外部服务。边界采用 0.002 度显示简化，近边界城市可能有误差；未覆盖地区（如境外和台湾的城市级划分）不编造城市名，显示“未识别区域”入口。Worker 失败提供重试且不阻断地图；卸载时终止 Worker，丢弃过期结果。底图沿用既有开关与瓦片请求。

## 验收与边界

使用 5191/8191 合成 API 和真实 Chrome 检查延迟导航、延迟数据、侧栏草稿、键盘、桌面/手机、明暗及减少动态效果。城市测试使用上海/北京两城，确认广州等无记录城市不存在；比较真实地图图像变化和复位，检查记录/热区与快照请求不变。纯逻辑测试覆盖穿越城市但无内部采样点、分段不连线、日期变更线、热区包含/孔洞及未覆盖范围。运行 pnpm check、相关单元测试、UI 回归及生产构建。

不改后端、接口、Schema、登录授权和统计口径；不读写数据库、密钥，不提交或发布。现有脏工作区原地保留，实施前已将目标文件备份至临时目录。
