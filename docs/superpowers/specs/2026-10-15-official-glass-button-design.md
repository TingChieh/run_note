# 按官方 lg-button 修正玻璃按钮

用户用官方按钮截图指出现有呈现不一致。现场核对官网 docs、官网 components.js 与 GitHub 固定提交，三者确认胶囊按钮采用独立玻璃 / 染色 / 阴影层、12px 扩展区域及弹簧按压（左右各扩 5px、上下各缩 2px）。此前只复用核心引擎，直接给原生按钮加背景滤镜与渐变，缺少完整组件结构与运动。

沿用原生按钮 / 链接及 Svelte action，参照官方 Surface / LgButton 分层适配，不替换业务 DOM 与事件。普通操作按钮使用胶囊外形，地图工具、日期和活动卡保持现有专用形状。玻璃独立装饰层有 aria-hidden、pointer-events:none，文字与图标保持原位；按压只改变玻璃几何，不改变按钮点击范围、布局或文字。为鼠标、触摸、键盘提供反馈并清理弹簧和监听。

保留开发调节及分段组轻阴影策略；使用同一官方默认光学参数，分段组适当减弱。开发预览提供 clear / tinted / light 三种染色，以已知 CSS 底纹的本地副本演示跨引擎内容折射；普通页面任意背景仍为 Chrome 背景折射、其他引擎磨砂回退。不复制运动地图、私人 DOM、轨迹或真实图片，不添加外部资源请求。

验证：先确认缺少装饰层与按压反馈的 UI 用例失败，再实现；原生表单、动态状态、按压几何与固定点击范围、 reduced motion、强制颜色、减少透明度、浅深色 / 桌面手机截图、开发设置与实例销毁均需复核。运行相关 Chrome 合成 UI、类型检查与构建。开发后端及数据库保持关闭 / 不操作。
