# 运动足迹最近记录与柔和切换

用户确认仅移除底部年月选择器，保留记录本身日期。运动足迹使用既有本人活动接口读取当前分类最近 20 条，省略日期/月筛选，不再追加分页；左右箭头在这 20 条内切换。分类、详情入口与记录日期保留。

切换分类或记录期间保留旧地图、指标和布局，新详情及路线读取完毕再更新；标题与指标数值淡出/淡入，卡片背景保持稳定。加载提示使用局部轻量状态，避免覆盖地图的大色块；快速完成的请求不闪提示。地图沿用原实例和底图开关，已绘制过的嵌入地图不再因换轨迹重复显示绘制提示。

保留请求令牌、失败重试和会话失效时立即清除私人数据的边界；普通失败不销毁已显示内容。减少动态效果时直接更新。空分类明确显示空状态。

仅改前端与合成 API UI 回归。既有 `readActivities` 已固定 limit=20 并按服务端日期顺序返回，后端、接口、数据库、环境配置不变。不启动效果预览、不提交或部署。

验收覆盖：跨月份最近 20 条、无月份控件/追加加载、分类与空分类、桌面/手机慢请求期间的地图实例和几何稳定、数值动画、减少动态效果、晚到响应、错误重试和 401 清理。执行相关 Chrome UI、`pnpm check` 和构建，区分合成环境与真实后端验收。
