# 按钮来源浮层动效

用户要求所有按钮弹出菜单（包含地图图层、日期和年月选择）从触发控件内部出现，选择或关闭后缩回同一位置。保留现有配色、玻璃材质、浮层最终位置与业务行为。

## 设计

采用共享几何计算与 CSS 双向过渡。相比固定顶部缩放，实际按钮中心和尺寸能处理日历右侧图标、贴边菜单和向上展开；相比逐帧 JS 弹簧，不新增常驻循环或改变原生 Popover 生命周期。

展开 380ms，位移和缩放略微越过终点后落稳；关闭 220ms，向按钮收缩并淡出。使用原生 display/overlay 离散过渡保留退场，关闭后不再接收指针操作。首开及快速重开先提交已测量的收缩态，再开始动画。

## 范围与边界

- 全站增强 select（包括日历内年份、月份）在 select 本体中心展开。
- DatePicker 在日历图标按钮中心展开，面板仍按原规则定位。
- RouteMap/FootprintMap 共用 BasemapPicker，使用稳定按钮容器计算来源。
- 文档流导航、城市展开区、details、删除确认 dialog 沿用其原有语义，不转成浮层。
- 不修改公共接口、后端、权限、时区语义、存储或数据库，不提交或发布。

## 验收

真实 Chrome 暂停过渡，独立对比面板起点/退场终点与按钮矩形；验证嵌套菜单、选择、Esc、外点、快速重开、焦点恢复、320/390/1440 宽度、浅深色和 reduced-motion。展示及 UI 测试只用合成数据。结果记录在编号验收文档。
