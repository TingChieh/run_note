# 跑步记录整理与成就展示

用户确认：多选只批量删除，编辑按单条；名称、分类、标签需能快速整理；5/10/20 km 按真实距离自动显示成就，分类/标签手动保存。

- 详情统一图标大字指标：距离、设备用时/运动时间、配速、经过时间（有设备时间时单独保留）、平均心率、热量、步数。缺失显示 —，真实 0 保留。开始时刻仍单独显示时区。
- 列表每卡展示私人足迹缩略图（复用 IntersectionObserver 懒加载与本地 SVG）、名称、运动指标、分类、标签及最高已达成的 5/10/20 km 徽章；阈值按未四舍五入的实际米数判断。
- 列表复选框、当前页全选、清空选择与已选数量，单卡编辑/删除；编辑在原页弹窗中完成。切换页或刷新列表清空选择，避免对不可见记录操作。
- 单条编辑标题、备注、分类（自定义短文本 0–30 字符）、标签（0–10 个，每个去首尾空白后 1–30 字符，保序去重）。分类提供轻松跑/节奏跑/间歇跑/长距离/比赛等建议，但可自由输入。全部为私人整理字段，公开分享不增加分类/标签。
- 后端新增非空 category（默认空串）和 tags（字符串数组，默认空数组），提供迁移 0008_activity_labels；不改既有指标与原文。后台只接受本人、Origin/CSRF 校验。
- 批量删除 POST /api/v1/activities/batch-delete，body={ids:[UUID...]}，1–100 个不重复 ID。锁用户行后验证全部归属，全部存在且本人方可同事务删除并递增一次数据版本；混入他人/不存在记录返回 404 且无部分删除。成功 data={deleted:true,deleted_count:N}。
- 原生删除确认框说明数量及永久删除影响，失败保留选择，可重试；成功更新当前页，如末页清空则退回上一有效页。
- 保留现有 dirty checkout 与环境配置，不提交/推送；新增迁移先在隔离测试库验证，开发库升级遵守既有需明确授权的约定。

## 用户反馈调整：紧凑卡片与编辑模式

用户明确要求：进入编辑后才允许选择，记录卡片恢复原来的紧凑大小，仅显示一张小足迹。

- 默认浏览模式只显示记录内容、详情链接和标题右侧小足迹，不显示选择框、批量工具条及单卡管理按钮。
- 列表标题旁提供“编辑”按钮，进入后显示选择、单条编辑/删除和批量操作；按钮变为“完成”，退出时清空选择。翻页仍清空选择，刷新回到浏览模式，保存/删除中不能切换模式。
- 记录卡片采用原有文字与三列运动指标的紧凑排版。足迹桌面约 104×78px，手机约 80×60px；使用组件的可选 compact 外观，足迹墙继续使用既有尺寸。保留实际距离成就和分类标签，长内容自然换行。
- 验证编辑模式显隐、键盘进入/退出与选择清理、标题/标签编辑和批量删除回归，以及桌面/320/390/768px 卡片尺寸、预览尺寸、懒加载、暗色与溢出。只改前端，不启动开发后端或改数据库。
