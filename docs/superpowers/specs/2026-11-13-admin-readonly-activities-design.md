# 管理员只读查看运动记录设计

## 目标与边界

管理员从用户管理页查看任意账号的记录、详情、私人备注和轨迹；普通用户和未登录者不能访问。只读接口按目标用户约束查询，不提供写入能力，也不读取身心健康日记。本人接口和分享权限保持不变。

## 方案

管理员专用端点复用活动 service 的列表、详情和路线查询，以目标用户 ID 作为归属条件，并先确认账号存在。另设仅返回用户 ID 的管理员活动归属端点，供本人详情 404 后跳转；非管理员不查询该端点。替代方案是在前端汇总用户和活动，既无法可靠定位分页数据，也会扩大接口访问，故不采用。

前端使用独立只读页面和活动 API 的运行时解析器，复用指标与地图组件；不渲染写入、分享及导出控件。服务端守卫及后端权限共同保护页面与数据。通过账号详情获取横幅名称。

## 验证

使用隔离 PostGIS 测试库验证授权、资源归属、筛选分页和既有写接口隔离；使用 Vitest 校验接口响应和错误；使用合成 API 及桌面、手机 Playwright 检验页面与跳转。
