# 液态玻璃导航、菜单、滑块设计

## 已确认范围

用户已在独立预览确认接入；随后要求选中项采用更大的统一圆角，并将参考图全部光学参数加入开发调节。沿用当前绿色竖向侧栏、图标、名称、尺寸、路由及移动导航结构；仅调整材质与动效。交互控件用胶囊圆角，卡片和菜单面板用 24px 圆角。

## 组件与交互

- 导航指示器纵向跟随鼠标及键盘焦点，离开返回 `aria-current="page"`，按压形变不改变点击区域。
- 调节滑块保留原生 range、标签、数值、键盘与持久化；拇指静止为浅色实体，按下透明、膨胀，释放回弹。
- 既有单选 select 渐进增强为磨砂下拉菜单；原 select 保留值、绑定、change/input、disabled 和表单语义。不改变页面操作，不新增演示菜单。方向键移动高亮，Enter/Space 选择，Escape/Tab 关闭，支持字符检索。无引擎或无 Popover API 时使用原生 select。
- 所有玻璃仍使用已有本地引擎；导航只复制固定导航文字/图标，菜单只复制选项文字，不复制页面内容、地图或轨迹。

## 接入后反馈调整

用户补充要求：年月菜单保持在日历内且不跑到左上角；所有同类下拉框右侧加入主题色箭头按钮，箭头随展开旋转、按钮按压缩放；菜单具有展开与收起动画，重复点击入口能够关闭。原生 select 保留为键盘和表单入口，箭头不额外占据 Tab 顺序。

子菜单挂载到所属 popover/dialog 内，使用未变换尺寸定位，滚动仅发生在菜单内部。年份长列表只对视口大小的装饰副本进行滤镜处理。年/月控件之间保留间距，焦点环内收，避免碰到相邻按钮。

照片调节区按钮按压时，背景副本围绕按钮中心作轻微横向放大与纵向压缩，折射强度和高光同按压弹簧联动；松开回到静态参数。普通按钮使用实际 backdrop 模式并联动折射，不复制页面内容。减少动态效果时不执行形变。

## 光学调节

保留 transparency；新增/扩展 refraction 0–60、bezel 0.1–1、curvature 2–6、ior 1.3–2、chroma 0–0.3、blur 0–8、highlight（specular）0–1、specularWidth 1–4、lightAngle -180–180。旧存储缺少字段时补默认值；非法及非有限值回退，越界截断。生产构建不显示调节器、不读取开发存储。

小型滑块、导航高亮及分段按钮使用较低折射比例保证文字/数值可读；调节作用于同一引擎实例。减少动态效果取消弹性；减少透明度或强制颜色禁用光学装饰并保留原生操作。深色跟随系统。

## 验证与边界

单元验证参数兼容与截断；真实 Chrome + 合成 API 验证指示器归位、菜单选择/键盘/禁用、滑块按压、调节记忆、系统偏好及 320/390/1440px 溢出。执行 pnpm check、pnpm test、pnpm build 和相关 UI 回归。开发真实 API/数据库不用于测试；不改后端、接口、Schema、认证、代理、环境文件；不提交推送。
