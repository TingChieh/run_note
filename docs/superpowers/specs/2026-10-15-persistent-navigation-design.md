# 常驻导航与紧凑跑量目标

用户已要求直接改动：左侧菜单常驻，右侧按需加载，已加载内容不要因普通点击或后台检查闪动；跑量目标缩小，自动主题按钮双向收放。

采用 SvelteKit 既有客户端导航，移除私人页面内部链接的强制文档加载。根布局保留 AppNavigation；右侧按 pathname 切换页面，覆盖详情 ID 变化时 onMount 重新读取的约定。同一菜单的普通点击不重复导航，修饰键仍保留浏览器行为。右侧路由资源等待时显示细加载条，原页面继续显示；数据等待沿用各页面现有局部占位，不增加延时或全屏遮罩。

后台身份检查成功时保留可见内容与草稿；检查失败继续清除私人页面，身份变化和跨标签退出继续跳转。公开链接、认证接口、代理、数据库和业务计算保持既有行为。

跑量目标减少内边距、字号、间距；目标进度与编辑入口保留，输入草稿与保存功能保留。低高度桌面进一步压缩菜单与账户留白；极短屏仍允许侧栏滚动，不截断内容。自动主题按钮使用已有双向过渡，尊重减少动态效果偏好。

验证使用独立合成 API 与 Chrome，不操作用户日常页面、不写开发库。验证菜单切换前后侧栏 DOM、目标草稿、文档请求数，延迟路由加载时右侧进度和左侧可用性，同菜单点击与后台检查不重建内容，前进后退、移动导航、身份失败和跨标签退出；检查常见短屏侧栏以及目标编辑高度稳定。

后续用户明确要求手机导航弹出动画与主题按钮逻辑可读：小屏菜单采用顶部轻缩放与淡入、关闭收回，保留同一个菜单实例；关闭立即 inert，当前菜单键盘激活后焦点回导航按钮；减少动态效果时取消过渡。主题按钮文字和图标表示当前日间/夜间模式，title 明确切换目的，aria-label 保留操作含义。

常驻目标摘要在活动成功导入、编辑、删除后通过本地事件重读；普通导航与焦点检查不重读摘要。摘要更新使用独立请求令牌，不清空目标输入草稿。身份核验失败仍隐藏姓名/邮箱和私人内容。
