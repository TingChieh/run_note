# 分享图多样式设计提案

日期：2026-10-17。用户要求增加可选生成样式，并明确删除图片底部「统计覆盖所选范围全部记录 · 半马为距离折算」。用户已选择「按四种实现（推荐）」，以下为已确认设计。底部这句已按明确要求移除。

## 方案比较

1. 推荐：四种完整排版预设。更换构图、指标位置与路线容器，形成实际可辨认的风格差异；复用同一组路线和当前主题，不增加配色编辑器。
2. 仅提供颜色预设。实现较少，但构图相同，满足多样式选择的程度有限。
3. 自由排版编辑器。可拖动模块、调字体与颜色，但配置与手机操作较复杂，不纳入本轮建议。

## 推荐的四种样式

| 样式 | 构图 | 视觉特征 |
| --- | --- | --- |
| 经典足迹（默认） | 现有黄色公里数页头 → 规整轨迹网格 → 底部统计 | 保留当前品牌识别与使用习惯 |
| 极简画廊 | 小字标与范围 → 大号公里数 → 无外框轨迹阵列 → 细线分隔统计 | 更多留白、更少色块，突出路线形状 |
| 运动海报 | 绿色主视觉与大号数字 → 路线网格 → 横向统计条 | 强数字层级、黄色强调线，运动感更强 |
| 足迹手账 | 标题与日期 → 带细边框的路线小卡 → 简洁统计栏 | 轻微错落的小卡片与页码式序号，像路线收藏册 |

四种都使用 RunNote 现有 background/surface/foreground/primary/primary-foreground/sport-yellow/border 等实际主题 Token、系统字体和 R 字标；同时支持站点浅色与深色外观。不要用额外照片、网络字体、外部图片服务或另一套独立品牌色板。错落卡片须位于各自网格格子内，不相互覆盖；最多120条时仍可辨识。

## 使用方式

「生成分享图」弹窗的范围控件下增加「图片样式」选择区，每项显示名称、简短构图示意与可见选中状态。默认经典足迹；小屏两列，原生单选控件支持键盘和焦点。

首次选好范围和样式后生成。已有预览时切换样式，复用已获取的 PosterData 在本机即时重绘，不访问 API、不重新抽样；「换一组轨迹」才重新抽取。样式选择保留在当前组件生命周期内，不增加持久化偏好。生成或系统分享期间禁用样式选择，避免旧 Blob 与当前选择不一致；主题变化继续通过现有 appearance/token 机制重绘。

四种均输出单张1080×1920 PNG，预览、下载、系统分享使用同一 Blob。截图中的底部说明不进入任何样式；「距离约等于」「次半程马拉松」保留在相关指标旁。随机展示 K/N 的信息保留，避免把路线抽样数当作全部活动数。

## 实现与边界

扩展 `route-poster-render.ts`，增加类型明确的样式枚举和渲染分支，共享路线绘制/文字/面板基础能力；`RoutePosterDialog.svelte`负责选择和现有数据重绘。不新增通用分享框架。`route-poster-data.ts` 的扫描、排除无轨迹、全范围最多120条随机抽样与四并发规则保持不变。

不改后端、公开接口、统计口径、认证与权限、数据库或全局主题，不上传图片或真实轨迹。保留现有取消、请求令牌、401清理、Blob URL释放、系统分享回退与Escape焦点恢复。此次实现授权不包含新的 Git 提交、推送或部署。

## 验证计划

- Chrome 合成 API：四种样式各实际导出 PNG，校验尺寸、像素差异与下载内容；截取少量/120条路线、浅深色、手机与桌面图片人工核对重叠/裁切。
- 切换样式不触发 API、不重抽路线；生成、分享、范围变化、主题变化、关闭和取消保持一致状态。
- 四种样式均不绘制截图中的底部说明，半马指标仍清楚表示距离类比。
- 单选控件键盘、可见焦点、390px与320px无横向溢出；既有分享图UI回归、`pnpm check`、前端单测和生产构建。
- 合成 UI 不代表真实账户、手机系统分享、Safari/Firefox或生产验收。
