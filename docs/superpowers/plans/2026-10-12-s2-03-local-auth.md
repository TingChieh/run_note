# S2-03 本地认证验收与前端接入

范围来自本轮明确授权：只接入已有 FastAPI 认证，不提交 Git，不迁移或清理数据库，不开始 S2-04。

## 设计与文件职责

- `scripts/local-auth.py`：以独立权限 600 文件持久保存随机 HMAC 密钥，仅注入后端进程；不改 `.env`、不打印密钥。精确固定本地来源 `http://127.0.0.1:5173`。
- `frontend/src/lib/api/auth.ts`：同源凭据、CSRF 获取、统一错误；无模块级身份缓存。
- `frontend/src/lib/server/backend.ts`、`routes/api/[...path]/+server.ts`：固定内部 API 目标转发，保留 Cookie、Origin、CSRF 与 Set-Cookie；开发及构建后的 Node 服务共用。
- `hooks.server.ts`：每请求核对会话；保护 `/activities`、`/dashboard`、`/settings`；私人页面及 load 返回 no-store。
- `+layout.server.ts`、`+layout.svelte`：请求级身份展示；焦点/跨页身份变化重新验证；私人内容在重新验证期间隐藏。
- `/login`、`/register` 及共享表单：原生密码/邮箱输入与错误提示，成功后整页导航避免上一个用户的状态复用；安全的站内 next 路径。
- 认证客户端单元测试及真实浏览器 E2E：注册、重复/错误密码、登录、刷新、退出、保护、双用户/双上下文/跨标签、过期、来源及 CSRF、SSR 无身份串用。
- README、阶段进度：记录真实证据及未验证范围。

## 执行顺序

1. 核对接口、来源、密钥、监听及开发/测试库当前版本，保存 `.env` 摘要。
2. 先编写安全客户端测试及浏览器验收用例，确认功能缺失失败。
3. 实现最小前端、同源代理及启动脚本。
4. 使用已在 `0003_gpx_storage` 的独立测试库运行认证集成测试（新增显式禁止迁移模式，仅只读版本预检）；迁移测试不运行。
5. 启动本轮 API 与前端，用随机新身份进行真实浏览器验收；保留注册数据，不删除记录。
6. 前端测试、类型检查、构建；后端 unit/auth integration、Ruff；构建后的 SSR/代理验证；复核 `.env` 摘要、库版本和监听。
7. 报告 S2-03 是否能关闭，停止任务，不开启下一阶段。
