# 液态玻璃控件接入计划

**目标：** 将已确认的导航、下拉菜单与滑块效果接入已有控件，并补齐光学调节。

**架构：** 复用本地 createGlass/createSpring，浏览器增强与 Svelte 业务 DOM 分离。样式使用既有令牌及新增圆角/菜单令牌，所有异步初始化均支持卸载清理。

**技术：** Svelte 5、TypeScript、原生 select/range、Popover API、现有 SVG 玻璃引擎。

## 约束

当前工作区仅有用户未跟踪 AGENTS.md，保留原状；用户明确授权继续接入，在当前工作区最小修改，不提交、不推送。只用合成 API 验证，不访问真实运动数据或数据库。
