# 身心健康两层开关

## 使用方式

管理员在用户管理中控制每个账号的「身心健康」许可；用户在设置的个人资料区控制自己的开关。两项均开启才显示入口。关闭后记录保留，重新开启后可继续读取。

## 接口与隐私

本人资料提供 `wellbeing_allowed` 和 `wellbeing_enabled`，仅后者可由本人修改；管理员可修改两者。任一项关闭时私人日记接口返回 404。日记仍不进入公开展示、分享或 AI 上下文。迁移默认开启，降级会拒绝丢失已关闭的设置。

## 验证记录

在临时原生 PostgreSQL/PostGIS 独立测试库上运行身心健康、隐私与管理员开关测试：83 项通过。前端类型检查 0 错误、0 警告，Vitest 282 项通过，样式 lint 通过；合成 API 的 Playwright 开关用例 2 项通过。后端全量回归为 839 项通过、3 项失败、1 项跳过；3 项失败涉及足迹后台和 GPX 超时，单独重跑均通过。这些检查不代表运行中的开发服务或生产环境已更新。
