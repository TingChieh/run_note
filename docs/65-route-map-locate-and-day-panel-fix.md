# 路线地图定位按钮与日面板裁剪修复

提交：`54c41f8`（定位按钮）、`426e363`（日面板裁剪修复）。两处均为前端小改动，合并记录。

## 使用方式

- **定位按钮**：`RouteMap` 左下角（与底图切换按钮对齐）新增圆形按钮"回到路线"。拖动、缩放或旋转地图后点击，地图以 700 ms 三次缓出动画飞回整条路线的包围盒，并将 bearing、pitch 复位为 0；系统开启"减少动态效果"时无动画。路线未就绪或地图出错时按钮禁用。复用 `button-secondary` 样式，没有新增地图实例或底图逻辑，也不调用 `map.setStyle`。
- **日面板裁剪**：仪表盘当天活动面板按内容高度做高度动画，但忽略了自身上下各 3px 的内边距（`border-box`），导致最后一张活动卡片的下边框被裁掉。现已把内边距计入，并使用小数内容高度。

## 接口与隐私

仅前端组件与样式改动，不涉及后端、接口、数据库与隐私边界；定位只使用浏览器内已有的路线包围盒，不产生任何第三方请求。

## 未实施项

- 定位按钮只回到整条路线，不提供"回到当前位置"之类的设备定位。
- 日面板高度仍由 `ResizeObserver` 驱动，未改动动画方式。
