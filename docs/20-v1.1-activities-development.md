## 实现结果

- 导入卡片将文件选择与主要操作放在一起，补充标题、时区、日期默认折叠；保留原有字段及说明，使用键盘可展开。
- 新增轻量 `ActivityCard` 和 `MetricSummary`；活动卡片呈现日期、标题、可见性、距离、用时、配速和质量概况。缺失指标仍显示“—”，并提供辅助技术说明，未推导或补造数值。
- 详情页先展示核心指标与响应式路线，再展示可展开的数据质量/指标说明和分享管理；保留所有质量计数、警告与指标版本。
- 地图加载/绘制错误/底图不可用提示放在地图外，保留起终点、GeoJSON 绘制、分段、OSM 署名、关闭/重试底图行为。地图与隐私说明通过 details 保留。
- 分享加载、提交中、成功与失败复用 P0 FeedbackState；分享范围说明可展开；保存可见性、期限、创建/复制/撤销链接的接口和载荷未改。
- 分开上传与列表错误：导入成功后列表刷新失败仍显示导入成功，列表自身提供重试，不再次上传文件。新增详情读取失败重试。
- 本轮未改 `app.css`、全局 layout、Dashboard、账户区、共享距离 formatter、后端/API/认证代码；这些文件的 P0 未提交变更仍保留。

## 复跑

在 `frontend` 目录，用已安装 Node 22 和依赖直接执行：

```sh
/opt/homebrew/opt/node@22/bin/node node_modules/vitest/vitest.mjs run
/opt/homebrew/opt/node@22/bin/node node_modules/@sveltejs/kit/svelte-kit.js sync
/opt/homebrew/opt/node@22/bin/node node_modules/svelte-check/bin/svelte-check --tsconfig ./tsconfig.json
/opt/homebrew/opt/node@22/bin/node node_modules/vite/bin/vite.js build
/opt/homebrew/opt/node@22/bin/node node_modules/@playwright/test/cli.js test --config playwright.ui.config.ts
```

UI fixture 只保存在内存/浏览器请求拦截中；专用测试目录为 `tests/ui`，不混入真实后端集成套件。临时 5191/8191 回环服务最终已停止，既有服务未停止。
