# 跑步回顾与分享图

## 使用方式

登录后，在本人的「个人记录」打开月度与年度报告，选择周期，点击「查看跑步回顾」。工作区回顾页支持保存带周期参数的链接，直接打开 `/workspace/records/recap` 时显示本人时区的今年。

总览显示总里程、跑步次数、跑步天数、总用时及平均配速。年度按月展示里程，月度按从周一开始的自然周展示，首末周裁到月界。当前周期截至本人时区的当天，已过的无跑步区段显示为零，未来的区段在完整数据表中标为「未到」。

点击「生成分享图」可预览 1080 × 1920 PNG，选浅色或深色，保存到设备。支持分享图片文件的浏览器还会显示「系统分享」。

## 接口与隐私

工作区页面沿用服务端登录门控，两次请求均使用本人会话。`GET /api/v1/statistics/report` 返回周期聚合和半开日期范围，`GET /api/v1/statistics/trends` 在同一范围内提供分桶聚合。发现里程或分桶边界不一致时自动重读一次。趋势无法读取时保留总览，图像生成会等待分布恢复。沿用现有接口和数据库结构。

预览提示聚合包含私人跑步记录。浏览器只把固定 RunNote 品牌、日期、总览指标和里程分布绘入 PNG。生成、预览与保存都在本机完成，分享功能通过浏览器调用系统文件分享。关闭预览、切换周期和离开页面会释放临时图片地址。

## 验证记录

- `pnpm exec playwright test --config playwright.recap.config.ts` 的 10 项合成 Chrome 用例通过，覆盖门控、入口、历史导航、等待与错误恢复、数据表、键盘、下载、主题及系统分享能力分支。系统分享通过合成浏览器能力验证。
- 合成测试输出 1440 × 900、768 × 1024、390 × 844 两种外观的页面截图，以及通过浏览器实际生成和下载的 PNG。专项用例另检查 320 px、当期截止文字、对象 URL 释放及导出过程的请求。
