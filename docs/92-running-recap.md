# 跑步回顾与分享图

## 使用方式

登录后，在本人的「个人记录」打开月度与年度报告，选择周期，点击「查看跑步回顾」。工作区回顾页（`/workspace/records/recap`）支持保存带周期参数的链接，直接打开时显示本人时区的今年。

页面采用「跑道年鉴（Editorial Monolith）」四章节布局：

1. **01 · 里程巨碑**：深森绿（深色模式下为暖炭绿）英雄区呈现超大总里程数字、等效全马/单次均距/峰值参照、峰值占比与活跃周期标尺，以及跑步次数、跑步天数、总用时、平均配速和统计覆盖注记。
2. **02 · 里程地形与累计轨迹**：交互式 SVG 平滑渐变面积地形、金色峰值锚点与累计里程虚线。支持鼠标悬停、点击及键盘方向键（`ArrowLeft`/`ArrowRight`/`Home`/`End`/`Enter`/`Space`）逐月/逐周巡检，顶部胶囊实时显示该时段四维服务端聚合；底部提供可折叠的完整无障碍数据表。
3. **03 · 双联剖析（出勤节律矩阵 × 均配速走势）**：左栏以年度 12 枚 / 月度 4–6 枚同心进度环呈现每期活跃天数与跑步次数，并与第 2 章选中时段双向联动；右栏以反纵轴（越快越高）曲线与周期均线展示加权平均配速走势并高亮最快均配期。
4. **04 · 封存分享台与高清预览对话框**：页尾展示实时 9:16 迷你海报并支持快捷切换版式与明暗；页头「生成分享图」与分享台均可打开原生 `<dialog>` 预览并保存 `1080 × 1920` PNG（支持 **A 特刊 / B 环道 / C 存根**三款版式与浅色/深色外观；支持文件分享的浏览器还会显示「系统分享」）。

## 接口与隐私

工作区页面沿用服务端登录门控，两次请求均使用本人会话，未新增后端接口或数据库迁移：

- `GET /api/v1/statistics/report` 返回周期聚合和半开日期范围；
- `GET /api/v1/statistics/trends` 在同一范围内提供按月（年度）或按周（月度，周一开始、首末周裁到月界）的分桶聚合。

前端 `recap.ts` 保留并使用上述响应中的全部聚合字段，发现总里程或分桶边界不一致时自动重读一次；趋势读取失败时保留第 1 章总览并提供「重试读取分布」。展示派生（峰值占比、最快均配、活跃比例、累计曲线、等效全马、400m 圈数、单次均距）均为确定性呈现计算，不替代或重算服务端权威指标。

9:16 分享图严格执行白名单：仅在本机 Canvas 2D 绘制通用 `RunNote` 品牌、周期标题与日期/截止日、服务端聚合数字、无地理坐标的分桶分布及参照换算；不绘入姓名、用户名、邮箱、账号/活动 ID、标题与备注、轨迹坐标、起终点、城市/地名、头像、身心健康数据或可扫描二维码（C 版式底部纹样仅按分桶里程比例生成，为纯装饰图形）。预览弹窗明确披露「包含私人跑步记录的汇总」，关闭弹窗、切换周期/版式/外观及离开页面时自动释放 Object URL。
