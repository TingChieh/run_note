# 一起跑步

## 使用方式

管理员在用户管理中打开「一起跑步」许可，用户在设置的身心健康开关下方打开「加入一起跑步」，并开启「公开个人主页」。普通账号还须已启用且已开启个人展示；站主沿用现有站主展示规则。关闭任一必要开关后立即从一起跑步移除。访客可从导航进入 `/together`，切换周/月排行，在地图图例中选择一人或全部。

## 接口与隐私

迁移 `0028_together_switches` 为两级开关设置关闭默认值；管理员只可修改 `together_allowed`，本人只可修改 `together_enabled`，未获许可时不能开启。降级拒绝丢失已开启的设置。

`GET /api/v1/together` 无需登录，只纳入同时满足上述条件的账号；沿用具名完整展示规则，包含私人记录和精确路线，设置页明确提示。返回公开标识、昵称、运动汇总、最近最多 30 条动态和最近最多 500 段简化路线；地图不显示极区或跨日期变更线的轨迹段。周/月按服务端 UTC 日期计算。总数及排行数据由一次分组聚合查询计算，不按用户发查询。响应不包含邮件、备注、原始文件或身心健康数据；轨迹不发送给底图服务。

## 验证记录

在 `/tmp` 内独立 PostgreSQL 18/PostGIS 测试库执行迁移至 head，管理员和认证集成测试 33 项通过（含合成轨迹、日记和公开条件）；后端单元测试 457 项通过，Ruff 检查和格式检查通过。前端 `pnpm check` 为 0 错误、0 警告，Vitest 286 项通过；合成 API Playwright 测试 3 项通过，覆盖访客排行、地图参与者切换、设置仅提交改动字段及手机深色导航。上述不代表开发服务或生产环境已更新。
