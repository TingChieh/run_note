# 跟随设备的夜间模式

RunNote 自动读取设备的浅色／深色外观偏好，首次访问和切换页面即应用对应主题，页面打开期间设备偏好变化也会同步生效。没有明确深色偏好时使用浅色；不按时间或地理位置推断主题。

页面颜色通过 `prefers-color-scheme` 与语义 CSS 变量处理；图表和地图只更新颜色，保留表单草稿、趋势指标、地图视野、底图开关和足迹选择。挂载时注册设备变化监听，卸载时清理。登录、注册、私人页面和公开分享页面共用同一套主题。

深色采用深绿灰背景、柔和的黄色标题区域及浅绿色主色。跑量目标、日历档位与焦点、省份地图、路线缩略图、状态提示、原生表单与地图控件均已适配；主按钮使用独立文字色保证对比度。沿用现有 OpenStreetMap 栅格底图，在深色时降低亮度和饱和度；路线与热度数据含义保持一致。
