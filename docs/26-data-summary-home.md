# 数据汇总首页

日期：2026-10-14。

首页只承担数据汇总和功能导航，不展示「导入 GPX」按钮或相关文案；有数据及空数据状态均仅提供查看跑步记录的入口，导入操作位于跑步记录页面。

需求：打开项目即可查看个人数据汇总，并能进入全部主要功能，替换原来的项目概览和开发环境状态页面。

方案：复用现有 `/dashboard` 统计页作为唯一首页。相比复制一套统计页或新建多接口汇总，现有页已包含累计数据、年度指标、可交互日历、当天记录和趋势，也具备空数据、错误重试和会话过期处理。根地址通过服务端 303 跳转并保留筛选查询参数；未登录继续由原有 Dashboard 认证保护处理。

实施与验收计划：

- [x] 将根路由及无指定安全返回地址的登录/注册指向 `/dashboard`，保留合法 `next` 地址及外部跳转拦截。
- [x] 侧栏首项及品牌返回语义改为「数据汇总」，删除重复的概览入口。
- [x] 在统计页摘要之后增加记录、足迹、AI 分析、设置入口；分享管理通过记录详情进入，公开个人主页通过设置管理。仅进入 AI 页面，不触发生成请求。
- [x] 更新原有首页说明和依赖旧页面/默认登录地址的测试。
- [x] 验证单元测试、类型检查、构建，以及真实 Chrome 的首页/统计/导航/公开布局回归；检查桌面和窄屏截图、键盘入口、横向溢出与匿名访问保护。

范围：前端页面、导航、默认返回地址与对应说明/测试；使用隔离内存 fixture，不写开发数据库、不调用付费 AI、不修改环境配置，不提交或推送。

验收结果：47 个前端单测通过，`svelte-check` 为 0 errors / 0 warnings，生产构建成功；Dashboard、UI shell 和 P2 的 23 项真实 Chrome 回归通过。首页用例补充统计加载等待后单独复跑通过。验证根地址保留查询参数、匿名访问跳转登录、默认登录进入汇总、合法设置返回地址、功能入口、键盘导航，以及 320/390/768/1440px 页面无横向溢出。

按用户补充意见移除首页所有 GPX 导入按钮和文案后，Dashboard 的 5 项真实 Chrome 回归、类型检查和构建再次通过；有数据和空数据测试均断言首页没有 GPX/导入文字。只读代码审查未发现本轮引入的可操作问题。
