# RunNote V1.1 P1 Footprints 开发记录

## 范围与设计（2026-10-13）

保留已验收 P0、Activities 和 Dashboard；只调整 Footprints 页面与 FootprintMap，不修改空间算法、API、数据库、认证或 .env，不使用 Docker，不提交/推送，完成后停止。

地图为主视觉；页面顺序为模式按钮、可折叠时间筛选、当前范围与记录数量、地图、热度图例/记录入口、折叠说明。手机筛选默认收起，地图保持至少 420px 操作高度；地图底图状态与按钮放在画布之外，避免遮挡。轨迹与热力模式用 aria-pressed 明确当前模式。

固定 100×100 EPSG:3857 投影米网格和 distinct_activity_per_cell 不变，图例仍为 1、2–3、4–7、8–15、16及以上。每个记录在同一格只贡献一次；GPS 点密度、同次绕圈及段数不增加热度。完整空间口径与底图隐私说明放入可展开区域。

### 范围与验证边界

本轮产品文件仅 Footprints 页面和 FootprintMap；另新增 UI 测试/开发记录，更新 UI 测试配置及 Dashboard 测试的布局等待。现有 P0/Activities/Dashboard 与其他工作树改动保留。

浏览器使用独立内存 HTTP fixture 与合成 GeoJSON，通过现有 SvelteKit 登录流程和私有路由验证 UI/API 契约，无数据库写入；未重跑真实 FastAPI/PostGIS 集成与空间算法性能，也未做实体手机/屏幕阅读器实测。201 格分页回归验证表格的懒渲染和索引，不代表后端空间聚合或 20,000 格地图容量验收。成功瓦片场景使用本地 PNG 响应验证加载路径，不宣称线上 OSM 可用性。

截图中瓦片请求被主动阻断，以展示“底图不可用但私人足迹仍可查看”的状态；几何仍由真实 MapLibre/WebGL 绘制。手机为 Chrome 视口模拟。没有修改数据库/用户数据/.env/认证/后端统计规则，没有执行 Docker、付费 AI、Git 提交或推送。

### 遗留项

仍保留既有 Footprints history.replaceState 路由提示、Dashboard replaceState 弃用提示、MapLibre/ECharts 大包警告及缺失 favicon；这些不属于本轮地图 UI 范围。没有发现未解决的本轮阻断问题。

### 复跑

在 `frontend` 目录执行（使用已安装 Node/依赖，不触发 pnpm 网络安装）：

```sh
node node_modules/vitest/vitest.mjs run
node node_modules/@sveltejs/kit/svelte-kit.js sync
node node_modules/svelte-check/bin/svelte-check --tsconfig ./tsconfig.json
node node_modules/vite/bin/vite.js build
node node_modules/@playwright/test/cli.js test --config playwright.ui.config.ts
```

本阶段完成后停止，不进入 P2 或其他功能。
