# 目标、足迹地图与足迹墙

日期：2026-10-14。

后续更新：本记录中的浏览器目标存储方案已由 [跑量目标后端保存](28-running-goals-backend.md) 替代；启用需要执行 `0006_running_goals` 数据库迁移。

需求：数据汇总首页加入省份点亮地图，以及年度/月度/周目标和连续记录卡片；每次跑步生成卡片，全部活动排列成足迹墙。用户已确认足迹墙为活动卡片网格。

设计：沿用现有绿/黄运动主题，参考卡片的进度条、对比与周历结构。目标未设置时明确显示未设置，不使用截图里的目标/里程。目标沿用当前按用户和周期区分的浏览器本地设置，主区域与侧栏同步。统计按账户时区确定当前周期，历史日期仍按活动保存的当地日期归属；同期比较采用截至今天的同等日历进度，缺失耗时显示未知。

省份地图默认显示 Dashboard 所选年度，34 个省级区域各算一次，海域轮廓不计入分母。通过本地静态省级边界与本人轨迹相交计算，返回省级聚合，不调用第三方定位服务。提供点亮区域列表、加载/错误/空状态和原有详细路线地图入口。地图边界仅用于可视化估算，近边界结果可能有误差。

足迹墙位于受现有认证保护的 `/activities/wall`，一条记录一张路线/日期/里程/耗时/配速卡片。原始路线仅供本人查看；无轨迹或缺失指标不会虚构。分页覆盖全部历史记录。新导入成功后刷新列表即可自动出现，不新建照片上传或公开路线接口。首页显示近期预览和全部入口，活动详情可查看自己的卡片。

实现计划：

- [x] 先测试当前/最长连续日与周、跨年/时区同期边界、断段路线卡片投影与省份归属，再实现数据辅助函数。
- [x] 增加只读 `/statistics/streaks` 与 `/footprints/provinces?year=`，复用本人过滤、既有数据库与事务超时，保留匿名及跨用户隔离；没有表结构变更或迁移。
- [x] 本地保存公共地图边界与来源说明；实现省份 SVG 卡片及可访问区域列表。
- [x] 实现目标与连续记录卡片，接入真实摘要、重试、目标设置及账户隔离。
- [x] 实现路线卡片、足迹墙分页、首页预览、上传成功和活动详情入口。
- [x] 完成前端/后端单测、类型与构建、真实 Chrome 的桌面/手机/键盘、失败/慢响应和身份隔离检查，记录真实数据库验收边界。

约束：保留已有未提交改动和 `.env`；不写开发数据库、不执行迁移、不调用付费服务、不提交、推送或部署。地图静态数据下载不包含任何用户信息。首页继续不显示 GPX 导入操作或文案。
