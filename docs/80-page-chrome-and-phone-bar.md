# 80 页面外壳配色与手机顶栏收放

跟在 [78 顶部导航](78-top-navigation.md) 之后的两处统一：

1. 页面外壳里残留的“旧绿色/黄色大色块”换成与顶部玻璃条同一套中性材质，绿色只作强调色。
2. 手机（<800px）顶栏改成“下滑收起、上滑一点就出现”，不再要求回到页面最顶部才能点菜单。

## 使用方式

### 页面外壳配色（浅色暖、深色中性）

先把残留的黄/绿大色块全部换成中性灰，用户反馈浅色“太冷淡”，于是浅色改成方案 B：深色保持中性。

| 位置 | 浅色 | 深色 |
| --- | --- | --- |
| 页头（`.page-header`） | 淡奶油黄圆角卡片（`--header-tint`），深褐黄文字 | 中性深灰圆角卡片（`#3a3735`），内边距、圆角与浅色完全相同 |
| 活动详情 hero、登录说明（`.sport-hero`、`.auth-intro`） | 同页头的奶油黄（`--hero-bg`） | `--surface` 卡片 + `--border` 边 |
| Logo 方块 | 品牌绿 + 白字 | 中性浅灰 + 深字 |
| 当前导航胶囊、头像底 | 淡绿（`#e3f3d9`）+ 深绿字 | 中性灰 |
| 玻璃主操作按钮 | 品牌绿染色（`--action`） | 中性灰染色 |
| 分段控件的选中滑块 | 淡绿（`--segment-lens`） | 中性灰 |

绿色（`--primary`）始终是强调色：数字、链接、进度、图标、开关与滑条的开启状态。数据色（热力、路线、指标圆点、省份）不变。`--sport-yellow` / `--sport-heading-ink` 保留，只给海报标题块与分享预览读取，所以海报外观不变。令牌取值见 [Tokens](design-system/tokens.md)。

### 手机顶栏

- 外观与桌面顶部条一致：圆角胶囊、距屏幕边缘 `--top-navigation-offset`、`--surface` 底 + `--border` 边；页面滚到它下面后变成清透玻璃（`data-floating`，与桌面同一套 docked/floating 规则）。
- `.app-shell > header` 在 <800px 吸顶（`position: sticky; top: 0`），header 自己的留白不拦截点击（`pointer-events: none`，子元素恢复）。
- 向下滚动累计 12px 后用 420ms 缓入缓出的滑动加淡出收起（结束后 `visibility: hidden`）；向上滚动累计 4px 就用 340ms 滑回，不必回到页面顶部。最初的曲线（260ms、前快后慢）大半个位移在 100ms 内就走完，看起来像一下消失，所以改成现在这样。收起的终点比 header 再高 2.5rem：栏的阴影（下偏移 .5rem、模糊 1.5rem）在栏滑出后还拖在屏幕上，`visibility: hidden` 一切断阴影就突然消失，要等它也离开屏幕再切。动画里不要给 header 加 `opacity`/`filter`：会让它成为 backdrop root，栏里的玻璃就看不到后面的页面了。滚到顶部（栏高度以内）一律显示。
- 菜单是挂在栏下方的圆角卡片覆盖层（`position: absolute`，完整边框，高度不超过视口，自身可滚动），不再把正文向下推；菜单展开时栏不会收起。
- 状态在 `AppNavigation.svelte` 的 scroll 监听里计算（rAF 合并），写成 `.mobile-bar` 的 `data-hidden` / `data-floating`；`prefers-reduced-motion` 下无动画。≥800px 的桌面顶部条行为不变。
- 另外修了一处：<480px 时分段标签（`.settings-tabs`）的按钮文字是居中的，滑块里那份文字副本（`createIndicator`）没有复制 `justify-content`，所以选中的字比真实按钮偏左约 8px；现在副本会复制它。

## 接口与隐私

只涉及前端样式与导航组件，没有后端、接口、数据库、鉴权或公开数据边界的改动；没有新增请求。

## 验证记录

见本次交付说明里的实际命令与结果；新增测试：

- `tests/ui/top-navigation.spec.ts`：手机顶栏样式（胶囊、距边缘、docked 实心/floating 清透、菜单是带完整边框的圆角卡片）；分段滑块里的文字与真实按钮居中对齐（361/390/1440）；手机顶栏收放（收起是持续数帧的滑动加淡出、不是瞬间消失；下滑收起、短距离上滑出现且仍远离顶部、菜单展开时不收起且贴在栏下方、桌面宽度不受影响）；页面外壳配色（浅色：页头是填色卡片并等于 `--header-tint`，Logo 为绿，导航胶囊/滑块/主操作有色；深色：页头是同样大小的中性灰填色卡片，Logo/导航/滑块/主操作都是低彩度灰；另有一条断言切换外观前后页头与分段控件的位置、尺寸、内边距、圆角完全不变）。
- `tests/fixtures/segmented.ts` 与 `top-navigation.spec.ts` 里原先写死“主色/白字”的断言改读新令牌。

## 未做 / 已知

- 浅色的灰色（`--muted`、`--border`、`--foreground`）仍带一点绿调，没有跟深色一样改成暖灰；`--primary-soft` 的浅绿底（文件选择、信息小标签）保留作为强调的淡色。
- 触屏上的“滑回即出现”只用 Playwright 的鼠标滚轮验证，没有在真机或 iOS Safari 验证（地址栏收放会影响 `scrollY` 的抖动）。
