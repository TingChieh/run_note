# 分享图四种可选样式

日期：2026-10-17。用户已确认四种样式实施，本轮未提交、推送或部署。

## 使用方式

在站主、具名展示或工作区的足迹墙点击「生成分享图」，选择范围和图片样式，再点击「生成预览」。

| 样式 | 生成效果 |
| --- | --- |
| 经典足迹（默认） | 黄色公里数页头、带底板的路线网格、左右统计卡 |
| 极简画廊 | 无色块大号公里数、留白与细分隔线、无外框路线阵列 |
| 运动海报 | 绿色大页头、数字与斜线强调、路线面板、底部三列统计 |
| 足迹手账 | 收藏册式标题、带本地序号的路线小卡、轻微错落、底部统计 |

选择区提供SVG构图示意、可见选中态与原生radio键盘操作。预览已生成时，点击其他样式会在本地重绘同一组路线；点击「换一组轨迹」才重新读取并随机抽样。生成/重绘或系统分享期间样式禁用。范围变化会清除旧图，关闭再打开保留当前组件的样式选择；刷新页面恢复经典足迹，不新增本地存储偏好。

所有样式输出单张1080×1920 PNG，复用当前网站浅/深色主题与系统字体。所选范围全量统计、排除无轨迹、最多120条等概率抽样与单图规则保留。最后一行「统计覆盖所选范围全部记录 · 半马为距离折算」已移除；半马指标旁的「距离约等于」「次半程马拉松」与「随机展示 K/N 条轨迹」仍保留。

## 接口与隐私

后端、数据接口、数据库、统计计算、授权/CSRF/SSR代理均无改动。`route-poster-data.ts`保持原有全范围抽样和最多4并发路线读取。四种样式只消费既有白名单统计与抽象路线；切换样式不读取接口、不上传图片、不调用地图或AI。

生成图片只写像素，不写坐标元数据、身份、备注、文件名或活动ID。手账上的序号仅是当前图片的本地排列次序，不是活动ID或日期。图片仍可能通过轮廓被辨认，沿用预览中的用户确认提示。预览、下载、系统分享使用同一Blob；取消和关闭继续清理URL并阻止旧异步结果覆盖。
