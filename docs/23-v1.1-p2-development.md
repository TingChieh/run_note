## 设计与实施顺序

复用 P0 的 PageHeader、FeedbackState、MetricSummary 和设计变量。登录注册保留原生校验和安全跳转，增加密码显示及提交反馈；设置按账户、资料、公开范围分组；AI 突出主动生成入口，统计细节默认折叠，历史及重试状态统一；公开主页强调指标与年度日历，公开摘要不引入私人详情组件；分享展示已保存权限与未保存选择。

2. 按上述范围调整组件与页面，不改 API 请求契约、权限、统计或撤销规则。
3. 运行前端测试、类型检查、生产构建及真实 Chrome 响应式检查，保存截图。

## 验收边界

浏览器使用 5191 / 8191 临时本地服务与合成数据；不会写现有开发数据库或调用 AI 提供商。公开接口故意注入私人字段哨兵，检查页面未渲染且未请求私人接口。此验收证明前端交互与接口契约，不代表真实数据库集成验收。

## 结果

PASS：本轮 P2 已完成，停止于辅助页面改造。

- 登录/注册：共享表单、原生必填/邮箱/用户名/密码约束保持不变；新增密码显隐、提交禁用与状态播报；服务端错误将键盘焦点移至错误区域并关联表单，失败清空密码，安全 next 跳转不变。
- AI：统一页面标题、生成入口、历史与报告卡片；日期控件手机竖排；周表、统计口径、覆盖率和质量说明默认折叠；距离显示 0–1 位小数（未改内部数值）。补齐统计/报告读取重试、加载与空数据导入入口。保留明确同意、额度说明、失败扣额、原幂等标识及刷新后恢复，不自动生成或调用真实提供商。
- Settings：账户信息、资料与公开开关分区；长邮箱在内容卡片内可换行而不溢出；显示已保存开关状态及未保存草稿；忙时禁用，成功/错误反馈统一。关闭主页与独立分享的不同撤销范围仍可访问。
- 公开主页/摘要：复用标题、指标和反馈；日历内年份切换，18px 格子、局部横向滚动与方向键；公开距离精简；空/关闭/撤销/失效可重试。保留既有独立公开接口、白名单、noindex/no-referrer、隐藏清理和重新读取机制，无地图、GPX 或私人详情请求。
- 分享：显示已保存权限与未保存选择；复制按钮统一；分享列表读取失败可重试，复制失败保留手工复制入口；保存私人、创建链接、到期/撤销规则保持不变。
