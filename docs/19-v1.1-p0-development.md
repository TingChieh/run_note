# RunNote V1.1 P0 开发记录

日期：2026-10-13（Asia/Shanghai）。设计依据：`18-v1.1-ui-ux-plan.md`，仅执行 P0。

## 实施方案

采用现有 Svelte 5 / Tailwind 4，保持认证和业务契约；不安装新的 UI 库。相比继续顶部换行导航，固定侧栏能稳定呈现活动、统计和足迹入口；相比移动端底栏，可展开菜单能容纳全部现有路由及退出入口。

- [x] `app.css`：品牌/语义色、字体、间距、圆角、控件状态、焦点、卡片和内容容器；保持日历局部滚动。
- [x] `AppNavigation.svelte` / `+layout.svelte`：桌面侧栏、移动展开菜单、当前页和子路由高亮、Escape 关闭与返回焦点、跳转主要内容；公开页面轻量页头。保留原有身份检查和退出函数。
- [x] `PageHeader.svelte` / `FeedbackState.svelte`：统一标题与四种反馈；对必要页面作轻量接入，不重新组织业务内容。
- [x] Chrome 回归：320/390/768/1440 视口，键盘导航、匿名 SSR 访问控制、登录、刷新、退出失败/成功、跨标签身份变化；截图。UI 测试使用独立 HTTP fixture，仅有内存会话及合成数据，不连接数据库。结果不等同于真实后端业务验收。
- [x] 运行前端单测、类型检查、构建，检查差异并记录结果。

## 工程边界

保留原有未提交变更；不修改后端、数据库、环境文件或密钥；不用 Docker 或付费 AI；不提交或推送。沿用当前工作区以包含已修复的 GPX 构建来源配置。测试服务器使用独立端口，不停止既有服务。


## 用户可见变化

- 浅色背景、白色轻边框卡片、克制的青绿色强调色；统一标题、正文、控件、圆角与内容宽度，不引入渐变或装饰性重阴影。
- 1024px 及以上固定侧栏；较窄视口使用顶部导航开关，菜单在正常文档流展开，不遮挡内容。当前页面及活动子路由高亮，保留全部现有导航入口。
- 登录/注册和公开页面使用轻量品牌页头；已登录公开页面保留返回运动统计及退出入口。账户长邮箱可以换行。
- 新增 PageHeader、FeedbackState，少量接入 Activities、Dashboard、Footprints、Settings 和 AuthForm。加载、成功、错误、空状态有统一反馈；已有反馈文字也共享基础样式。
- Tab 焦点、跳过导航入口、Enter 开关/链接、Escape 收起并返回开关焦点、语义导航/当前页/展开状态及减少动画偏好均已加入。
- 首页仅修正旧的“功能尚未实现”文案，没有重新组织业务区。

## 复跑命令

在 `frontend` 使用已安装依赖与 Node 22：

```sh
/opt/homebrew/opt/node@22/bin/node node_modules/vitest/vitest.mjs run
/opt/homebrew/opt/node@22/bin/node node_modules/@sveltejs/kit/svelte-kit.js sync
/opt/homebrew/opt/node@22/bin/node node_modules/svelte-check/bin/svelte-check --tsconfig ./tsconfig.json
/opt/homebrew/opt/node@22/bin/node node_modules/vite/bin/vite.js build
/opt/homebrew/opt/node@22/bin/node node_modules/@playwright/test/cli.js test --config playwright.ui.config.ts
```

使用现有 CLI 直接执行，避开本机 pnpm 自动获取指定版本时的网络元数据访问；未更改 packageManager 或 lockfile。UI 专用配置测试目录为 `tests/ui`，不会让普通集成配置混入 HTTP fixture 测试。仅临时使用 5191（前端）和 8191（fixture）回环端口，最终已退出；既有服务保持原状。
