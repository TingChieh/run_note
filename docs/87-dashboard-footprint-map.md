# 87 数据汇总足迹地图：光点地球与纸雕平面图

数据汇总页“足迹地图”卡片（`frontend/src/lib/components/ProvinceMap.svelte`）的视觉重做。底图退为安静的纹理，绿色只表示“跑过这里”：3D 全局是光点地球，2D 是纸雕平面图。接口、数据计算与后端均未改动。

## 使用方式

- **3D 地球**：全局视角下陆地由光点组成，没有边界线与经纬网格；光点向球的边缘缩小，地球外有一圈光晕。访问过的省份里的光点变绿并放大约 1.5 倍，访问过的城市按活动次数用更深的绿（日历计数色阶同一色系）；比光点间距还小的地点会在中心补一个绿点。光点间距按地球实际显示大小自适应（约 3px，限制在 1.2°–2.0°），手机与桌面密度一致。
- **放大**：按“每度占多少屏幕像素”切换。先在仍然实心的光点下方淡入陆地轮廓、省份与城市填充（3.5–5.5 px/度），再让光点淡出（5–7 px/度），避免两层同时半透明造成一瞬间发白。
- **2D 平面图**：始终是纸雕效果（光点按球面均匀排列，摊到平面会错落，所以不用于 2D）。陆地是白纸并在海面投下固定屏幕距离的错位阴影，访问过的省份是平铺的浅绿填充（不加阴影：浅色下错位的绿色阴影像套印没对准），边界只保留细线。
- **默认视图**：首次打开是 3D 地球；之后记住本机上一次选择的 2D/3D（`localStorage` 键 `runnote-footprint-view`，读写失败时按 3D 处理）。
- **2D/3D 切换**：一次飞行（约 1100ms，CSS `ease` 曲线，对数高度插值），中心点不动。球面到平面的形变只跟着高度走、不跟着时间走：只在一段区域级的高度带内发生（带底是 2D 首页视野的高度，带宽为 2 倍缩放），速度与镜头缩放同步，镜头慢下来它就慢下来、停下时已经完成，所以不会在静止画面上单独“演”一段拉伸；这段高度里看不到高纬度，也就没有墨卡托在极区向上鼓起。切到 2D 时地球俯冲、边缘移出画面，切到 3D 时平面拉远并在上升中卷成球。飞行未穿过高度带时（例如在已放大的地球上切到 2D），形变改在飞行中段完成。飞行途中的任何操作会让它立即落到终点；“减少动态效果”时直接到位。
- **镜头**：视场角 12°（原 32°）。宽视场在区域级缩放下会让球面像鱼眼一样鼓起，切到平面时还要把它拉回来；缩小视场去掉了鼓起，也让地球与平面在 2D 首页视野下的固有差异减少约两成（实测 600×272 舞台：左右边缘约 50→38px、角落约 71→54px，剩下的是球面上纬线弯曲这一几何事实）。距离上下限按视场换算（`fovReach`），可见范围与原来一致。
- **自动旋转与点亮**：3D 全局视角下无操作 3.5 秒后，地球缓慢向东转（约 4°/秒），起停都平滑过渡；转动时去过的地方转到正面才亮起、转向边缘时变暗。指针在地图上、任何操作、放大到省份、卡片不在屏幕内或页面隐藏时都会停下；“减少动态效果”时不转。每次切到 3D 都会重放一次光点点亮动画。
- **拖动**：跟手 1:1，平面按每像素对应的距离平移，地球按每像素对应的弧度旋转（高纬度经度方向相应放大），没有拖动时的缓动延迟和单步上限。松手时按最后 80ms 的速度惯性滑行并逐渐减速；停住再松手则不滑行；“减少动态效果”时不滑行。
- **缩放**：鼠标滚轮一格约 25%，触控板的连续小增量平滑缩放，触控板捏合（ctrl + wheel）单独换算；平面图以指针为锚点，地球放大时视图中心向指针漂移，指针下的地点基本不动。
- **选中**：不画轮廓线。选中的省份颜色深一档、光点更大；选中城市时其他城市向所在省份的填充色退后。
- **首次出现**：访问过的光点按固定的伪随机顺序在 1.4 秒内依次亮起，填充同步淡入；系统开启“减少动态效果”时直接显示最终状态。
- **悬停**：桌面鼠标移到访问过的地点上显示“省份 · 城市 · N 次活动”的提示，光标变为指针；拖动、滚轮缩放或移出地图时隐藏。触屏不显示，地图下方的省份/城市按钮仍是可访问的主要入口。
- **卡片其余部分**：标题右侧为“N 省/州 · N 城市”大数字（读取中或失败显示“—”）；国家切换为 `.compact-switch`，只有两个以上国家时显示；省份与城市为中性胶囊，选中为 `--primary-soft` 底加主色边框；2D/3D 切换沿用原按钮。

色板集中在 `frontend/src/lib/map/footprint-colors.ts` 的 `GLOBAL_MAP_PALETTE`（WebGL 需要具体色值）；深色外观使用同一套设计。

## 接口与隐私

- 只消费既有 `readGlobalFootprints`（`/api/v1/footprints/global` 与 `/api/v1/showcase/footprints/global`），没有新增或修改接口、响应结构、数据库或后端代码。
- 光点由前端从仓库内的 `world-base.json` 边界数据生成（扫描线法，约 7ms），不发起任何第三方请求；轨迹与坐标不离开浏览器。
- 悬停提示只显示接口已返回的地名与次数。
