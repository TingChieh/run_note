# 82 跑步记录：时间线列表与桌面预览栏

日期：2026-11-02。设计与取舍见 [spec](superpowers/specs/2026-11-02-activity-master-detail-design.md)。接 [81](81-activities-views.md)：“足迹墙”并入“跑步记录”之后，原来的活动卡片（约 255px 高、两列）太大，改成下面的样子。

## 使用方式

- **列表**：按月分组的时间线。月份胶囊旁是当月合计（本页只有半个月时写“本页 N 次 · X km”，不冒充整月），行左是日期列和一条竖线，行右是一张紧凑卡片：路线缩略图、标题、成就/分类/标签、“时间不完整”标记、距离·用时·配速。不再写“公开展示”和“查看活动 →”。
- **桌面（≥1024px）**：左栏时间线（固定 26rem），右栏是选中记录的预览：路线地图、指标、开始时间、完整度、编辑/生成分享图/删除、“查看完整详情 →”。右栏吸顶。点击一条只是选中；Ctrl/Cmd/中键仍然在新标签打开详情页。上下方向键换选中项。选中项写进地址（`?id=`），刷新、前进后退和分享链接回到同一条；地址里的 id 不在本页时选第一条。
- **窄屏**：只有时间线，点击进入详情页（与以前一样）。
- **对齐**：桌面两栏的第一行对齐：左栏第一个月份胶囊和右栏预览标题在同一条水平中线上（都是 1.75rem 行高，左栏顶部留 `1rem + 1px`，正好抵上右栏卡片的上边框和上内边距），右栏卡片的上边与列表列的上边齐平。
- **导入**：页面上方的两个导入区块折叠到标题行的“导入轨迹”按钮后面，展开/收起是高度动画（420ms，`grid-template-rows` 0fr↔1fr 加淡入淡出，下面的列表跟着滑动；收起后 `visibility: hidden` 且 `inert`，里面的东西不会被聚焦），按钮里的箭头同时旋转 180°，`prefers-reduced-motion` 下无动画。默认收起；记录为空、导入进行中或有结果提示（成功、警告、错误）时自动展开。区块始终挂载、用 `hidden` 收起，所以选好的文件和批量进度不会丢。
- **批量管理**：“编辑”后行首出现复选框，行尾出现“编辑 / 删除”（行为不变）。

## 接口与隐私

只涉及前端：没有后端、接口、数据库、鉴权或公开数据边界的改动，没有新增请求类型。右栏只在选中时读取该记录的路线（沿用 `readRoute`，窄屏不挂载右栏所以不会白读）；失败只在右栏显示重试。`?id=` 是公开展示页本来就有的活动 id，不含新信息。

## 验证记录

以交付说明里的实际命令与结果为准。新增或改动的测试：

- `tests/ui/activities.spec.ts`：按月分组与合计（含被分页截断的月份）；默认选中第一条、地址与预览同步、刷新后还原；方向键；窄屏无预览且点击进详情；预览路线读取失败只影响预览且可重试；预览里编辑/删除走列表的对话框；批量选择；导入区默认折叠/按需展开/保留已选文件/空库自动展开。
- 对齐与动画：月份胶囊与预览标题中线相差 ≤1px、预览卡片上边与列表列上边齐平；展开和收起各至少 5 帧可见的中间高度、箭头旋转、收起后标题不可见。
- `tests/fixtures/activities.ts` 新增 `openImport`，所有要操作导入表单的用例（activities、activity-batch-import、activity-library、mifitness、tcx、crossbrowser-glass）先展开导入区。
- `tests/ui/activity-cards.spec.ts`、`activities.spec.ts` 里原先断言“公开展示”、卡片高度 ≤300、地址恰为 `/activities` 的几处按新行为改写。
