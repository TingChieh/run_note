## 性能数据

### 方法与限制

本机 loopback，单用户串行，每个主要规模 3 次；独立空间 service/SQL 是另一次查询测量，**不是 HTTP 时延的精确分解**。SQL 数值来自 SQLAlchemy 执行事件，含语句执行与结果返回到驱动的时间。数据库缓存较热，没有生产并发、网络限速、固定 CPU 负载或 p95/p99；没有预设容量合格阈值。所有数值是实测样本，不外推线性扩展能力。

### 地图底图原因排查

已用独立 Chrome 页面等到底图状态结束再拍照：9 个真实 OSM 瓦片请求均 200，约 309–492 ms；同 URL fetch 200，15,040 字节。最终截图可见道路和标注。未复现持续失败，不能断言存在 CORS、API Key、URL 或瓦片供应商故障。

快速响应式截图是在 route ready（本地轨迹）时捕获，底图异步请求尚未完成；离开页面产生 `net::ERR_ABORTED`，不是服务拒绝。故障测试的 `net::ERR_FAILED` 是主动 abort 注入，不能混入自然失败统计。已有 8 秒超时/错误回退移除底图，但保留轨迹；重试、关闭和重新开启均通过。当前有 `/favicon.ico` 404，属于图标缺失，不是底图失败原因。
